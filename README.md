# 💰 Money Wise

> A personal-finance application concept for tracking spending, categorising transactions and understanding financial habits.

## ✨ Intended experience
- Expense and income tracking
- Transaction categories
- Weekly / monthly summaries
- Spending analysis
- Simple, user-friendly workflows

## 🚀 Run
```bash
git clone https://github.com/javinarora05/Money-Wise.git
cd Money-Wise
npm install
npm start
```

## 🧭 Direction
The goal is to evolve this into a stronger finance-management product with richer analytics and budgeting workflows.
